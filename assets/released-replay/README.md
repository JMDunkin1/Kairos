# Released leveraged ETF NAV replay for hub review

This is a reproduction of the already-released **NAV-PROXY BACKTEST**, January 2, 2024–October 1, 2026: 690 observed sessions per definition. It creates zero new strategy trials. The preferred research candidate is **lev_core_relative_leverage_sleeves_v3**, classified `HIGH_RISK_RETROSPECTIVE_NAV_RESEARCH_CANDIDATE`. Monthly 50% TQQQ / 50% QQQ is an `EXPOSURE_BASELINE_NO_TIMING_EDGE`, retained as a useful comparison. Both are historical, high-risk research definitions. Neither is a proven edge or an exchange execution system.

The candidate produced 39.41% net CAGR, 149.02% net return and -37.02% maximum drawdown. The fixed 50% TQQQ / 50% QQQ baseline produced 41.62% CAGR, 160.03% return and -42.32% drawdown. The candidate therefore **did not improve raw return over this 50/50 baseline**. It exceeded its separately defined development-mean-holdings static comparator (36.49% CAGR) by 2.92 percentage points. SPY, QQQ and actual leveraged buy-and-hold comparisons remain in `released_comparison_metrics.csv`; actual TQQQ, UPRO and QLD buy-and-hold had higher CAGR than the candidate. This is descriptive evidence from familiar historical regimes, with selection over 48 configurations. The prior bootstrap interval for annual log excess over its own static comparator spans zero; it does not establish timing alpha.

## Exact funded rules

1. **Candidate:** At a completed monthly NAV signal, calculate QQQ and SPY total-NAV return over 252 observed sessions. Start with 50% QQQ and 50% SPY. If QQQ return is strictly positive and strictly exceeds SPY return, replace the QQQ half with TQQQ, leaving 50% SPY. If SPY return is strictly positive and strictly exceeds QQQ return, replace the SPY half with UPRO, leaving 50% QQQ. A tie or two nonpositive returns retains the underlying 50/50 allocation. Insufficient history holds SHY. No additional trend filter or negative-momentum cash exit is present.
2. **Exposure baseline:** Rebalance monthly to 50% actual TQQQ and 50% QQQ. This is a static exposure allocation, with no signal-based timing claim.

The exact frozen `lev_families_core.py`, `lev_engine.py` and `engine.py` bytes are copied into `code/`. `code/definitions.py` exposes only these two definitions through `catalog()`, `targets(rule_id, total_nav)`, `execution_plan(rule_id, total_nav)` and `replay(rule_id, total_nav)`. It isolates the frozen engine import and accepts historical audited data only, through October 1, 2026. Its inputs are absent from this export. The `engine.py` file also contains a legacy exchange open/close simulator; the wrapper uses the copied **leveraged total-NAV** simulator and monthly schedule only. No legacy exchange fill claim is made.

## Chronology and ledger semantics

The first entry starts with $100,000 flat cash at the January 2, 2024 NAV, initialized from the last completed monthly signal on December 29, 2023. That prior signal date is provenance only; no pre-window source values are exported. There is no return into the first entry bar. A completed signal at t executes at the next observed audited NAV session. Prior holdings first earn the NAV movement; the trade follows, and newly sized holdings begin earning the following session's movement. The last session ignores any fresh scheduled allocation and sells existing holdings once. The final October 1, 2026 cash includes exit costs. Initial capital is included in the drawdown peak.

The ledger models funded, fractional, rebased NAV holdings with no external margin and zero idle-cash yield. Ordinary SPY/QQQ/SHY trading costs are 5 basis points per gross traded dollar; TQQQ/UPRO/QLD costs are 15 basis points. Entry, rebalances and terminal sale are charged and funded from wealth. Costs are assumptions for spread, slippage and premium/discount, with no actual fills, commissions, taxes or platform fees verified. Fund expenses are embedded in NAV. These are neither exchange prices nor achievable closing fills. No broker, actual paper account, order system or $2,000 whole-share performance has been validated.

`targets_and_execution.csv` distinguishes observation-day raw targets from the last completed monthly signal and already shifted execution targets. Daily raw targets do not imply daily trades. `execution_events.csv` lists first entry, scheduled monthly trades and terminal liquidation. `daily_nav_replay.csv` contains dollar holdings, trades, cash, fees, equity, returns and drawdown for each of the 690 sessions. Its terminal metric mark weights intentionally describe the holdings immediately before sale, matching the original audited metric convention; actual posttrade holdings are zero. No raw NAV levels, source prices, raw historical tables or unreleased data are included.

## Source and risk limits

The issuer total-NAV histories contain captured cash only. TQQQ 2016/2017, UPRO 2017 and QLD 2021 cash completeness remains uncertified; missing years are not assumed zero. The retained parent distribution snapshot is exact DOM text, not original HTTP response bytes. ProShares NAV and distributions are current-share-equivalent and already split adjusted: no extra split action is applied. The split CSV's November 21, 2025 date conflicts with the issuer's November 20 announcement; this source uncertainty remains. Parent-retained 1-month through 10-year performance checks agree within 0.48bps as a consistency check, not a cash-completeness certificate; lifetime UPRO/QLD residuals of 8.38/75.22bps include an earlier source window. Underlying SPY/QQQ/SHY source qualifications persist. Captured-cash omission is a sensitivity, not a bound on unknown missing cash.

Actual TQQQ/UPRO aim at 3× daily index performance and QLD at 2× daily performance; multi-day paths depend on daily resets and volatility. The replay uses the actual fund paths, not multiplied index returns. Contract-multiple exposure is a proxy, not realized beta or constant long-horizon leverage. Severe drawdowns, a fixed known-today survivor/availability-biased universe, prior source/regime exposure and historical selection limit confidence. Combined 2024–2026 overlaps the other released windows; it is not a new independent holdout. Partial-2026 CAGR in retained prior metadata is annualized and is not a forecast.
